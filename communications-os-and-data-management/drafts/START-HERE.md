# Start Here

This folder is an organized, privacy-conscious learning portfolio for the programming for cybersecurity course materials.

## Open the main sections

- [Study guide](../../notes/python-for-cybersecurity.md) - revised, plain-language notes.
- [Assignment drafts](README.md) - unfinished work grouped by HTML, Python, and Networking, in course order.
- [Source materials index](source-materials-index.md) - original inputs grouped by topic.
- [Portfolio overview](portfolio-overview-draft.md) - concise hiring-manager-facing description with honest status labels.

## Suggested order

1. Read the study guide sections on HTML and Python fundamentals.
2. Work through Draft 01, then Draft 02, then Draft 03.
3. Continue through the Python drafts before the networking drafts.
4. Follow each draft's numbered steps and save evidence only after personally running and checking the work.
5. Check the source index if the course prompt or an older example needs to be confirmed.

## Status labels

- **Draft - not started:** prompt is captured; work remains to be done.
- **Draft - needs review:** a supplied example exists, but it has not been validated as final work.
- **Reference only:** source material is retained for study and is not a deliverable.

The due dates shown in course screenshots are from 2022 and should be treated as historical. No student identifiers are included in this organized set.
