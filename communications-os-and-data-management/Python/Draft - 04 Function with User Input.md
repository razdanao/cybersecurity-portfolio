# Draft 04 - Function with User Input

**Status:** Draft - not started  
**Source prompt:** Python class 4 presentation assessment.

## Goal

Write a commented function that takes user input and returns a response.

## Work through these steps in order

1. Decide what information the program will ask the user for.
2. Write a function with a clear name and parameter(s).
3. Validate or convert input where needed.
4. Return a response from the function; print the returned value when calling it.
5. Add comments that explain intent, then test normal and invalid inputs.

## Completion checklist

- [ ] Function is defined with `def`.
- [ ] The input reaches the function.
- [ ] The function returns a value.
- [ ] Code includes useful comments.
- [ ] At least one normal and one edge case are checked.
