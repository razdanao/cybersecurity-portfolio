# Security+ Exam Alignment

> Checked against CompTIA's official pages on 2026-10-28. Re-check before relying on this: dates and objectives change.

## Which version is current?
| Version | Code | Status (as of 2026-10-28) |
|---|---|---|
| V6 | SY0-601 | Retired (2024). Your course decks still reference it. |
| **V7** | **SY0-701** | **Current**, in effect since late 2023 |
| V8 | SY0-801 | Announced; expected launch on or around **17 Nov 2026** |

CompTIA's V8 page lists 90 max questions, 90 minutes, passing score 750/900, English, and an estimated three-year life after launch. Certifications earned on V7 remain valid under CompTIA's renewal rules (check their CE policy).

## V8 domain weighting (from CompTIA's V8 summary)
| Domain | Weight |
|---|---|
| General Security Concepts | 16% |
| Threats, Vulnerabilities, and Attacks | 24% |
| Security Architecture | 19% |
| Security Operations | 27% |
| Security Program Management and Oversight | 14% |

New emphasis in V8 includes **AI-related risks** (models, prompts, privacy, data exposure), automation/orchestration, and cloud/hybrid/OT architecture.

## What this means for this repo
- This is a **coursework/portfolio** repo, not an exam-prep repo; align notes to concepts, not exam trivia.
- Use **SY0-701** terminology until you decide which version you will sit. Final V8 objectives may differ from the previews, so re-verify after launch.
- Course deck topics that still hold in either version: CIA, control types, threat actors, vulnerabilities, risk (SLE/ALE), authentication, cryptography basics, incident response, governance.
- Topics to add as optional extras (relevant to V8): AI security risks, automation, supply-chain risk.
