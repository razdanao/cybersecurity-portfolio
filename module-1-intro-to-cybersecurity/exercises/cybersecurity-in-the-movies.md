# Exercise: Cybersecurity in the Movies

**Task:** Watch an expert review how Hollywood portrays hacking, define five terms from the video, then rate a film or show of my choice for accuracy.

## Five terms
| Term | Definition |
|---|---|
| **Spear phishing** | A targeted phishing attack aimed at a specific person or organization, using personal details to look trustworthy |
| **CTF (Capture the Flag)** | A security competition where teams solve hacking and defense challenges to find hidden "flags" for points |
| **Credential stuffing** | Trying username and password pairs leaked from one breach against other sites, relying on password reuse |
| **SQL injection** | Inserting malicious SQL into an input field so the application runs it against its database |
| **ASCII** | A standard that assigns numeric codes to letters, digits and symbols so computers can exchange text |

## Accuracy rating: *The Matrix Reloaded*
**Rating: 9.5/10.** In one scene the character runs **Nmap**, a real, open-source network scanner, and then exploits an actual weakness in an old version of SSH (the CRC32 vulnerability). The on-screen commands and output match what a real attacker would see, which is rare in film. I stop just short of a perfect score because the pacing is compressed: real recon and exploitation take much longer.
